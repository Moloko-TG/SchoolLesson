# 4. uzdevums: Darbs pārī ar branch un merge

Šajā uzdevumā svarīgākais ir kopdarbs ar GitHub. Python kods ir ļoti īss.

## Sagatavošanās

1. Viens skolēns izveido repozitoriju un pievieno partneri kā collaborator.
2. Abi skolēni klonē vienu un to pašu repozitoriju.
3. Pirms darba abi pārliecinās, ka atrodas `main` branch.

## Skolēns A

1. Izveido branch `feature/sveiciens`.
2. Pabeidz failu `sveiciens.py`.
3. Izveido commit `Pievienots personisks sveiciens`.
4. Push branch uz GitHub un izveido pull request.

## Skolēns B

1. Izveido branch `feature/rezultats`.
2. Pabeidz failu `rezultats.py`.
3. Izveido commit `Pievienots rezultāta teksts`.
4. Push branch uz GitHub un izveido pull request.

## Kopā

1. Apskatiet viens otra izmaiņas.
2. Apvienojiet abus pull request ar `main`.
3. VS Code pārslēdzieties uz `main` un izvēlieties **Pull**.
4. Palaidiet `main.py`.
