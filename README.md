# Git un GitHub: Python atkārtojums

Šajā darbā tu atkārtosi Python pamatus un iemācīsies saglabāt izmaiņu vēsturi ar Git.

## Darba secība VS Code

1. GitHub atver skolotāja doto repozitorija saiti.
2. Izveido savu repozitoriju ar **Use this template**.
3. VS Code izvēlies **Source Control** un **Clone Repository**.
4. Atver visu repozitorija mapi, nevis tikai vienu Python failu.
5. Izpildi uzdevumu un palaid `main.py` ar pogu **Run Python File**.
6. Source Control panelī nospied `+` pie izmainītajiem failiem.
7. Ieraksti īsu commit ziņojumu un nospied **Commit**.
8. Izvēlies **Sync Changes** vai **Push**.
9. Pārbaudi GitHub, vai commits ir redzams.

## Svarīgi

- Commit ziņojumā raksti, ko tu izmainīji.
- Veido vairākus nelielus commitus, nevis vienu commit pašās beigās.
- Nekopīgo savu GitHub paroli ar citiem.
- Ja GitHub šobrīd nedarbojas, turpini veidot lokālus commitus VS Code.
